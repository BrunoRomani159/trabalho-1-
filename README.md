# Deepwoken para iniciantes

Página web estática que apresenta o jogo **Deepwoken** (Roblox) para quem nunca jogou: o que é, como o combate funciona, como montar um personagem e quais são os primeiros passos.

Trabalho Avaliativo 01 de **Desenvolvimento Web I** (Técnico Integrado em Informática para Internet, 2026).

## Site publicado

https://SEU-USUARIO.github.io/deepwoken-iniciantes/

## Tecnologias

- HTML5
- CSS3 (sem JavaScript, sem framework, sem tema pronto)
- Git e GitHub Pages

## Estrutura

```
index.html
css/style.css
README.md
RELATORIO.md
```

## Aviso

Projeto de fã, sem vínculo com os criadores de Deepwoken ou com o Roblox.
